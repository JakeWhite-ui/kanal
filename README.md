# Путь к 100 000 AED

Личный дашборд: прогресс к цели, сделки, посты, подписчики и журнал работы. **Приватный репо** — внутри суммы сделок.

## Запуск

```
cd ~/kanal && node server.js
```
→ http://localhost:4320

Зависимостей нет, нужен только Node. Графики — Chart.js с CDN, то есть для них нужен интернет; всё остальное работает офлайн.

## Что внутри

Одна лента, как страница в Notion:

| Блок | Что делает |
|---|---|
| **Паспорт** | Кто я, чем торгую, прайс, живые работы, каналы. Заполняется один раз, сохраняется на лету |
| **Прогресс** | Сколько собрано из 100 000 и процент. Считается только по сделкам со статусом «Оплачено» |
| **Деньги по месяцам** | Столбцы — сумма оплаченного за месяц |
| **Сделки** | Клиент, услуга, статус, дата, сумма. Статусы: лид → в работе → счёт выставлен → оплачено |
| **Подписчики** | Снимок раз в неделю по каждой площадке, график роста, таблица снимков |
| **Посты** | Карточки с рубрикой, площадкой, просмотрами и откликами + график просмотров по рубрикам |
| **Журнал** | День, минуты в работе, что сделано, провал дня |

Чего здесь намеренно нет: «нужно зарабатывать N в день», прогнозов и темпа. Дашборд документирует сделанное, а не подгоняет.

## Где живут данные

`data.json` в этом репо — единственный источник правды. Сервер переписывает его целиком при каждом изменении, через временный файл и rename, так что обрыв не оставит битый JSON.

**Так сделано ради синка между двумя Mac.** localStorage через git не ездит, файл ездит:

```
git pull  →  вносишь в дашборде  →  git add -A && git commit && git push
```

Пропустил pull перед правкой — машины разъехались, чинить руками.

## Правила, на которых это держится

- **Каждая сумма вносится с клиентом и датой.** Цифру, которую нельзя проследить, нельзя ставить в публичный отчёт.
- **Провал дня заполняется всегда.** Журнал без провалов через месяц не скажет, что ломалось.
- **Снимок подписчиков раз в неделю, в один и тот же день.** Иначе прирост не с чем сравнивать.
